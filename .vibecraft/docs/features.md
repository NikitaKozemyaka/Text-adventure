# Тёмные развилки

## Цель проекта
Дать игроку возможность пройти атмосферную текстовую историю с разветвлённым сюжетом, где каждый выбор открывает свою ветку повествования и приводит к одному из финалов.

## Основные возможности

### История с развилками
- **Цель:** Пользователь читает последовательные фрагменты сюжета.
- **Описание:** На каждом шаге истории игроку показывается текст текущего фрагмента и набор доступных вариантов продолжения. Выбор направляет в соответствующую ветку.
- **Критерии приёмки:**
  - После выбора варианта отображается новый фрагмент истории, соответствующий выбранной ветке.
  - У каждой ветки есть завершение — финал, после которого история не продолжается.
  - Доступные варианты показаны чётко и понятно.

### Выбор действий
- **Цель:** Игрок влияет на ход истории своими решениями.
- **Описание:** Каждый фрагмент предлагает от 2 до 4 осмысленных вариантов действий, каждый из которых ведёт к своему продолжению.
- **Критерии приёмки:**
  - Все варианты выбираются кликом по кнопке.
  - Разные выборы приводят к разным фрагментам истории.

### Финалы и переигровка
- **Цель:** Игрок может увидеть разные концовки истории.
- **Описание:** Дойдя до финала, игрок получает возможность начать игру заново с самого начала.
- **Критерии приёмки:**
  - По достижении финала отображается итоговый текст концовки.
  - После финала доступна кнопка начала игры заново.

## Дополнительные заметки
- Игра предназначена для одиночного прохождения.
- В первой версии сюжет статичен и задан заранее (без сохранения прогресса между сессиями).

## Дизайн-система

- **Источник визуального направления:** выбранный пользователем стиль «тёмное фэнтези»
- **Направление:** атмосферный тёмный интерфейс, приглушённые тона и акцентный свет
- **Визуальные принципы:** погружение в историю, спокойная драматичная атмосфера, внимание сосредоточено на тексте и выборе
- **Цвета:** тёмный фон (глубокий серо-синий/чёрный), светлый текст, акцентный янтарно-золотистый для ключевых элементов и интерактивных деталей
- **Типографика:** крупный читаемый заголовок, комфортный размер основного текста истории, выразительный акцент для вариантов выбора
- **Компоненты и состояния:** карточка фрагмента истории, кнопки-варианты с состояниями наведения, блок финала с итоговым текстом и кнопкой перезапуска
